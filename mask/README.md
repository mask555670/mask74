# MaskFit

A modern fitness tracking application built with React and TypeScript.

## Features

- Track your workouts
- Monitor your progress
- View exercise history
- Mobile-friendly interface
- Works offline (PWA)

## Installation

1. Clone the repository
2. Install dependencies:
```bash
npm install
```
3. Start the development server:
```bash
npm run dev
```

## Building for Production

To build the application for production:
```bash
npm run build
```

## Technologies Used

- React
- TypeScript
- Vite
- Material-UI
- PWA capabilities
